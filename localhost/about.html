About Legitalk

LegiTalk provides AI-generated transcripts and summaries of Connecticut government meetings. It combines searchable transcripts with meeting videos.

You can search through transcripts by bill, keyword, or speaker. Every sentence is linked directly to the original video source which allows you to play a video clip of any selected text by pressing the play button above the video.

Implementations and Source Code

The code for this project has been updated for use by CTMirror.org.
